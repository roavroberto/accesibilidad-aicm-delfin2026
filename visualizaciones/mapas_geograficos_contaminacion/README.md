# Mapas Geográficos de Contaminación - AICM

## 🗺️ Cómo ver los mapas interactivos

### Opción 1: Ver directamente en tu navegador (RECOMENDADO)

1. **Descarga el repositorio completo:**
   - Haz clic en el botón verde "Code" en GitHub
   - Selecciona "Download ZIP"
   - Descomprime el archivo

2. **Abre los mapas:**
   - Navega a esta carpeta: `visualizaciones/mapas_geograficos_contaminacion/`
   - Haz doble clic en cualquier archivo `.html`
   - Se abrirá en tu navegador (Chrome, Firefox, Edge)

3. **Explora los mapas:**
   - Usa el mouse para hacer zoom
   - Haz clic en los marcadores para ver información
   - Observa la leyenda en la esquina inferior izquierda

### Opción 2: Ver las imágenes estáticas

Si solo quieres ver una vista rápida, abre los archivos PNG en esta carpeta:
- `comparativa_espacial_Concierto_Foro_Sol.png`
- `comparativa_espacial_Gran_Premio_F1.png`
- `comparativa_espacial_Temporada_Decembrina.png`

## 📊 ¿Qué muestran los mapas?

Cada mapa muestra:
- **Rejilla de contaminación:** Distribución espacial de PM2.5 en la CDMX
- **AICM:** Marcador rojo con icono de avión
- **Venue del evento:** Marcador naranja con estrella
- **Estaciones SIMAT:** Marcadores azules con información

##  Notas importantes

- Los archivos HTML requieren conexión a internet para cargar los mapas base
- Se recomienda usar Chrome o Firefox para mejor compatibilidad
- Los mapas son completamente interactivos (zoom, pan, popups)
- La escala de colores va de azul (bajo) a rojo (peligroso)
